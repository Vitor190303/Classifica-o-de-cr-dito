
# Classificação de Risco de Crédito com Machine Learning

Projeto acadêmico desenvolvido durante os estudos de Ciência de Dados na EBAC.

## Objetivo

Explorar características de clientes e aplicar técnicas de classificação para estudar o risco de crédito.

O projeto utiliza um modelo Random Forest para classificar clientes de acordo com a variável de resposta `mau`.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Metodologia

O projeto acompanha etapas do CRISP-DM:

1. Entendimento do problema de negócio
2. Exploração e compreensão dos dados
3. Preparação e transformação das variáveis
4. Treinamento do modelo Random Forest
5. Avaliação inicial dos resultados
6. Discussão sobre possíveis aplicações

## Técnicas aplicadas

- Análise exploratória e visualização de dados
- Análises univariadas e bivariadas
- Transformação de variáveis categóricas
- Separação entre dados de treino e teste
- Treinamento de modelos Random Forest
- Cálculo de acurácia e matriz de confusão

## Estado atual

Este é um projeto acadêmico em desenvolvimento.

O notebook contém atividades orientadas da EBAC e experimentos iniciais de classificação.

Como próximas melhorias, pretendo:

- Documentar os resultados obtidos;
- Avaliar precisão, recall e F1-score;
- Comparar o modelo com uma referência simples;
- Aplicar validação e testes de reprodutibilidade;
- Melhorar a organização e documentação do notebook.

## Limitações

O modelo ainda não foi validado para utilização em decisões reais de concessão de crédito.

A acurácia isoladamente não é suficiente para avaliar o desempenho de um classificador, especialmente quando há desequilíbrio entre classes.
